# Security

Local MoE Studio is currently an alpha prototype. Do not expose the inference API to public networks or use it with sensitive documents before evaluating the platform's security.

Please report security issues privately to the maintainer through a private GitHub security advisory after the repository is published. Do not publish exploitable vulnerabilities in public issues.

User conversations and model settings are saved locally and are not encrypted at rest. The application can download external binaries and model files on explicit user actions. Review sources and installed model licenses.
